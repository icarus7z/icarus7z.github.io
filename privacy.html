개인정보처리방침

웹사이트와 Google Drive 연결에서
어떤 데이터를 어떻게 사용하는지 안내합니다.

시행일: 2026년 10월 28일

운영 및 적용 범위접근 데이터와 목적보관 및 전송데이터 사용 제한삭제 및 권한 철회웹사이트와 문의변경 안내

1. 운영 및 적용 범위

Pluto는 GitHub 계정 icarus7z가 개발·관리하는 Windows용 파일 관리자입니다. 개인정보 및 서비스 지원 연락처는 icarus.login@gmail.com입니다.

이 방침은 본 소개 웹사이트와 Pluto의 Google Drive 연결 기능에 적용됩니다. 로컬 파일 관리 기능은 사용자의 PC에서 파일·설정·작업 기록을 처리합니다. 사용자가 다른 프로그램이나 별도의 서비스에 파일을 전달하면 해당 서비스의 정책이 적용됩니다.

2. 접근하는 데이터와 이용 목적

사용자가 Google에서 승인한 범위에서 다음 데이터를 처리합니다.

  • 파일·폴더 정보: 이름, 식별자, 크기, 수정 시각, MIME 유형 및 제공되는 버전·해시 정보 등을 목록 표시와 전송 확인에 사용합니다.
  • 파일 내용: 다운로드·Google 문서 내보내기를 요청하면 해당 내용을 사용자가 지정한 PC 폴더에 저장합니다.
  • 업로드할 로컬 파일: 쓰기 권한을 승인한 사용자가 업로드를 지시하면 선택한 파일 내용을 Google Drive로 전송합니다.
  • 인증 정보: Google이 발급한 접근 토큰·갱신 토큰 및 만료 정보를 승인된 연결과 갱신에 사용합니다. Google 계정 비밀번호는 Pluto가 입력받지 않습니다.

기본 읽기 연결은 https://www.googleapis.com/auth/drive.readonly 권한을 요청합니다. 사용자가 쓰기를 선택하면 https://www.googleapis.com/auth/drive 권한을 요청하여 업로드·폴더 생성·이름 변경·삭제 명령을 수행합니다. 기존 Drive 파일 전체를 직접 탐색하는 기능에 해당 범위를 사용합니다. 권한을 승인해도 사용자의 명령 없이 Drive 파일을 자동 삭제하지 않습니다.

3. 보관 위치와 전송 경로

Drive 연결은 사용자의 PC에서 Google 인증·Drive API로 직접 통신합니다. 이 연결에 Pluto 운영자의 중계 서버를 사용하지 않습니다. 파일 목록은 열린 앱의 작업 상태에서 처리하고, 다운로드 파일은 사용자가 선택한 로컬 경로에 남습니다.

연결 이름·제공자·앱 ID·요청 권한 등의 설정은 %LOCALAPPDATA%/Pluto/cloud/profiles.json에 저장합니다. 로그인 저장은 기본적으로 꺼져 있습니다. 저장하지 않은 새 로그인은 해당 연결에서 사용하며, 별도 로그인 파일로 보관하지 않습니다.

새 로그인 저장을 선택하면 토큰과 필요한 데스크톱 앱 인증 정보를 Windows 사용자 DPAPI로 보호해 %LOCALAPPDATA%/Pluto/cloud/credentials에 저장합니다. 저장된 로그인과 연결 설정은 사용자가 삭제할 때까지 PC에 남습니다. 로컬 파일·설정의 접근은 해당 PC의 Windows 계정 및 저장소 권한에도 영향을 받습니다.

4. Google 데이터 사용 제한

Google API에서 받은 정보의 사용 및 다른 앱으로의 전송은 Google API Services User Data Policy와 그 Limited Use 요건을 따릅니다.

Pluto의 Google Drive 기능은 해당 정보를 사용자가 요청한 파일 탐색·다운로드·업로드·관리 작업에 사용합니다. 이 정보를 판매하거나 맞춤형 광고·신용도 판단에 사용하지 않으며, 범용 AI·머신러닝 모델의 학습에 사용하지 않습니다. 운영자가 사용자의 Drive 파일을 원격으로 열람하는 기능은 제공하지 않습니다.

사용자가 다른 프로그램으로 파일을 열거나 별도의 위치로 복사하는 등 직접 전달을 지시한 경우, 해당 프로그램·대상 서비스가 파일을 처리할 수 있습니다. Google 자체의 데이터 처리는 Google 개인정보처리방침에 따릅니다.

5. 연결 해제·로컬 삭제·권한 철회

  • 연결 해제: 열린 원격 연결을 종료합니다. 저장된 로그인·연결 설정·다운로드 파일까지 삭제하지는 않습니다.
  • 저장된 로그인 삭제: 클라우드 연결 창의 ‘고급 연결 설정 → 저장된 로그인 삭제’에서 해당 PC의 로그인 파일을 삭제할 수 있습니다. 이미 열린 연결은 별도로 해제하세요.
  • Google 접근 권한 철회: Google 계정의 연결된 앱 관리에서 Pluto의 접근 권한을 철회할 수 있습니다. PC의 로그인 파일 삭제와는 별개의 작업입니다.
  • 연결 설정과 다운로드 파일: 사용자가 PC에서 삭제할 때까지 남습니다. 연결 설정 제거가 필요하면 앱 연결을 종료하고 해당 로컬 설정을 정리할 수 있습니다. 다운로드한 파일은 저장한 폴더에서 별도로 삭제합니다.

6. 웹사이트 및 지원 문의

이 웹사이트는 GitHub Pages에서 제공하는 정적 페이지입니다. 사이트 자체에는 로그인 양식, 분석 도구, 광고, 외부 글꼴 또는 추적용 스크립트를 넣지 않습니다. GitHub는 서비스 보안을 위해 방문자의 IP 주소를 기록할 수 있습니다. 자세한 내용은 GitHub Pages 데이터 수집 안내와 GitHub 개인정보처리방침을 참고하세요.

이메일로 문의하면 발신 주소와 사용자가 보낸 내용을 문제 해결과 회신에 사용합니다. 지원 메일은 요청 처리에 필요한 동안 보관하며, 삭제를 원하면 같은 연락처로 요청할 수 있습니다. 비밀번호·인증 코드·로그인 토큰·개인 파일은 보내지 마세요. 문의 없이 파일이나 로그를 운영자에게 자동 전송하지 않습니다.

7. 방침 변경

연결 기능이나 데이터 처리 방식이 바뀌면 이 페이지의 내용과 시행일을 갱신합니다. Google 앱 검증 상태와 이용 가능한 연결 범위는 홈페이지의 연결 안내에서 확인할 수 있습니다. 현재는 테스트 계정 연결 단계이며 일반 공개 검증 완료를 의미하지 않습니다.
